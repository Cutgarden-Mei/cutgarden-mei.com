# Information Architecture

## MVP対象

- `/`: トップページ
- `/menu`: メニュー・料金
- `/staff`: スタッフ一覧
- `/staff/[slug]`: スタッフ詳細
- `/access`: アクセス
- `/voice`: お客様の声
- `/contact`: 問い合わせ

## 第2段階

- `/news`: お知らせ一覧
- `/news/[slug]`: お知らせ詳細
- `/privacy-policy`: プライバシーポリシー
- 外部予約サービスへの導線最適化

## 分類

### 固定ページ

- トップ
- メニュー・料金
- アクセス
- 問い合わせ

### 一覧/詳細ページ

- スタッフ一覧/詳細
- お客様の声一覧
- お知らせ一覧/詳細

### フォーム

- 問い合わせフォーム
  - 氏名
  - メールアドレス
  - 電話番号
  - 問い合わせ種別
  - 問い合わせ内容
  - 個人情報の取り扱い同意

## ナビゲーション

- ヘッダー: Home / Menu / Staff / Voice / Access / Contact
- 共通CTA: 電話予約 / Web予約 / 問い合わせ
- フッター: 店舗情報 / 営業時間 / SNS / ポリシー
